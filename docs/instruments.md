## Processing

- **Acoustic Kit**: Subset: 3 velocity layers x 2 round robins per piece; close and overhead mics mixed to mono; resampled to 44.1 kHz; silence trimmed; per-piece peak normalised to -1 dBFS; 16-bit WAV. Built with scripts/build-acoustic-kit.py.
- **Brass**: Imported from TromboneSus.sfz@34-53, TrumpetSus.sfz@57-84 with scripts/sfz-import.py: velocity layers first,last, up to 99 round robins, MIDI roots 0-127; mono, 22050 Hz, looped 1-3 s with a 300 ms crossfade; zone levels evened out (±12 dB max); one gain for all files (peak -1 dBFS); 16-bit WAV.
- **Clean Guitar**: Imported from emily_clean.sfz with scripts/sfz-import.py: velocity layers 2,4, up to 2 round robins, MIDI roots 40-88; mono, 22050 Hz, cut to 2 s with a 300 ms fade; one gain for all files (peak -1 dBFS); 16-bit WAV.
- **Electric Bass**: Imported from 05-darkblack_pluck.sfz with scripts/sfz-import.py: velocity layers 3,4, up to 2 round robins, MIDI roots 23-52 (keys transposed -12 to sounding pitch); mono, 22050 Hz, cut to 1.4 s with a 300 ms fade; one gain for all files (peak -1 dBFS); 16-bit WAV.
- **Electric Piano**: Imported from TX81Z - FM Piano.sfz with scripts/sfz-import.py: velocity layers first,last, up to 99 round robins, MIDI roots 36-96; mono, 22050 Hz, cut to 2.5 s with a 500 ms fade; one gain for all files (peak -1 dBFS); 16-bit WAV.
- **Grand Piano**: Imported from Grand Piano, Steinway B.sfz with scripts/sfz-import.py: velocity layers first,last, up to 99 round robins, MIDI roots 36-96; mono, 22050 Hz, cut to 2.6 s with a 500 ms fade; one gain for all files (peak -1 dBFS); 16-bit WAV.

## Rebuilding

- `scripts/build-instruments.sh NYLON EMILY BASS VCSL VSCO` rebuilds every SFZ-based instrument with `scripts/sfz-import.py` (the header of the script lists where each source comes from and the extra SFZ files to check out from the VCSL `sfz` and VSCO `SFZ` branches). Pass `-` to skip a source. Rebuilds are byte-identical for the same sources.
- `python3 scripts/build-acoustic-kit.py SRC` rebuilds the Acoustic Kit from Big Rusty Drums.
- `node scripts/make-test-instrument.mjs` regenerates the test instrument.
- After a rebuild, run `npm test` (manifests, licences, budgets, the regression projects) and listen to the instrument in the app. If the sound changed on purpose, run `npm run regression:update` and commit the new fingerprints.

## Backup

- Every source except one is on GitHub at the commit recorded in its manifest (`provenance.url`), so it can be fetched again exactly.
- The **Nylon Guitar** source (FreePats `SpanishClassicalGuitar-SFZFLAC-20190618.7z`, 4.7 MB) comes from freepats.zenvoid.org, which the build sandbox cannot reach. Keep a copy of the archive (for example in Google Drive) next to the project.
- The processed files in `app/public/instruments/` are themselves the deployed copies; GitHub Pages serves them and the service worker caches what a device has used (`musicmaker-instruments-v1`).

## Personal instruments

Instruments made in the app from your own samples (Library › Sample editor › Make an instrument) are not bundled. Their mapping is saved in the project and their audio in the browser's IndexedDB with your other samples; they never leave the device unless you export a WAV.
