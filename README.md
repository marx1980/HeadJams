# MusicMaker

A simple, beginner-friendly music-making app (web/PWA first). Pick a channel, choose a sound, set note length, and build loops.

Phase 1 (beat maker with tutorials) is complete. See `plan.md` for the roadmap, `docs/research.md` for the market research and `docs/architecture.md` for the architecture.

## Essential Commands
- Install: `npm install`
- Run: `npm run dev`
- Test: `npm test`
- Build: `npm run build`
