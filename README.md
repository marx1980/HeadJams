# MusicMaker

A simple, beginner-friendly music-making app (web/PWA first). Pick a channel, choose or record a sound, set note length, and build loops.

Phases 1–2 (beat maker, tutorials, and sound sampling) are complete. Import or record samples, trim and normalize them, then use them in your loop. See `plan.md` for the roadmap, `docs/research.md` for the market research and `docs/architecture.md` for the architecture.

## Essential Commands
- Install: `npm install`
- Run: `npm run dev`
- Test: `npm test`
- Build: `npm run build`
